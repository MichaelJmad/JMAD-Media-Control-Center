<h1>JMAD Media Tool: High-Level Plan &amp; Functional Specification</h1><p>This document outlines the complete functional requirements and technical scope for the JMAD Media Tool (Version 1). The tool provides an intelligent, state-aware, and highly customizable solution for organizing and standardizing media files before deployment to a live media server (e.g., Plex, Jellyfin). The core philosophy emphasizes <strong>absolute data fidelity</strong> and user confidence before any file system changes are executed.</p><h2>1. Core Workflow &amp; Application Philosophy</h2><p>The application utilizes a <strong>State Management</strong> philosophy, ensuring media titles progress through user-controlled states. This guarantees that files are fully verified, renamed, and metadata-rich before deployment, preventing common library errors.</p><h3>Standardized Status Protocol (UI Color &amp; Icon)</h3><p>The UI uses standardized color indicators and icons, which are fully customizable via <strong>Theme Profiles</strong> (Section 5.2), to communicate the necessary next action.</p><table><tbody><tr><th><p>Icon/Color</p></th><th><p>Status Name</p></th><th><p>Definition</p></th><th><p>User Action Required</p></th></tr><tr><td><p><strong>⚪ Gray</strong></p></td><td><p><strong>Unorganized</strong></p></td><td><p>Media is raw, unverified, or unrecognized. Requires initial title mapping.</p></td><td><p>Initiate <strong>Organize Dialog</strong> to map raw files to a standard title.</p></td></tr><tr><td><p><strong>🔵 Blue</strong></p></td><td><p><strong>Processing/Pending</strong></p></td><td><p>Media is named and structured, but <strong>full metadata (NFO/Artwork) is not finalized.</strong></p></td><td><p>Initiate <strong>Metadata Fetch</strong> and Finalize content.</p></td></tr><tr><td><p><strong>🟢 Green</strong></p></td><td><p><strong>Ready to Move</strong></p></td><td><p>Media has complete, verified metadata and structure. Main Application Components (Tabs)</h2><p>The application uses a multi-tab interface to manage the workflow:</p><ol><li><p><strong>Staging Directory:</strong> Primary workspace for organizing and state transitions.</p></li><li><p><strong>Live Libraries (Catalog):</strong> Read-only view of deployed media for diagnostics.</p></li><li><p><strong>Tools:</strong> Access to advanced utilities (Cleanup, Diagnostics, Patterns).</p></li><li><p><strong>Settings:</strong> Configuration hub for directories, naming, metadata, and appearance.</p></li></ol><h3>Right Panel Preview &amp; Organization Dialog</h3><p>The <strong>Organization Dialog</strong> is the main interactive tool for processing a single media title. It includes a <strong>Right Panel Preview</strong> to provide real-time visualization of the resulting file and folder structure <em>before</em> file system changes are committed.</p><h3>3. Final Operational Definitions</h2><h3>5.1 File Operation Safety &amp; Error Handling</h3><p>Critical file operations include robust safety checks:</p><ul><li><p><strong>Pre-Operation Check:</strong> Verify read/write/delete permissions before starting any major move or rename operation.</p></li><li><p><strong>Non-Critical Failure:</strong> Log failure to the <strong>Console Panel</strong>, continue the batch, and assign a <strong>Warning Flag (🟡)</strong> to the affected title.</p></li><li><p><strong>Critical Failure:</strong> Attempt a <strong>transactional rollback</strong> of partial operations.
