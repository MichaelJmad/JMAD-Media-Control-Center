# JMAD Media Manager — Development Roadmap
# and Wireframes
---

## Section A — Current Features (Baseline, Already Implemented)

### A1. Core Functionality

* Media renaming tool with configurable rename patterns.
* Series scanning from staging/root folder.
* Parsing of seasons, specials, and movies.
* Batch operations: rename, move, organize, clean files.
* Move-To presets in settings.
* Undo/Redo system for rename/move actions.

### A2. Metadata

* `.jmad_info.json` per series folder with flags:

  * `is_processed`
  * `media_type` (TV, Movie, Anime, Anime Movie).

### A3. Settings

* Settings stored in `settings.json`.
* Options for root folder, rename pattern, themes, move-to presets.
* Settings dialog GUI.

### A4. User Interface

* Main window (Tkinter + ttkbootstrap).
* Toolbar with \[Scan] \[Settings] \[Tools] \[Exit].
* Tools menu (Clean, Move-To).
* Left panel: series/seasons tree view.
* Right panel: preview panel + history panel.

### A5. Themes

* Multiple bootstrap themes supported.

* Replace History Panel → **Console Panel**:

  * Logs all performed actions.
  * Dockable/undockable.

* Repurpose Preview Panel:

  * Shows cover artwork and metadata.

### B2. Settings Dialog Rework

* **General Tab**

  * Rename Pattern (Episode + Movie):

    * Editable boxes.
    * Preset selection dialog with explanations + previews.
    * Custom builder with live preview (test series/movie).
  * Console visibility option (☑).
  * Directories unified in a single styled list:

    * Staging (mandatory).
    * TV, Movies, Anime (optional).
    * User-defined directories.
    * Each entry includes: “Include in Catalog ☑”, Options (⁞), Delete (⌫).

* **Patterns Tab**

  * Manage regex patterns for name suggestions.
  * Add, edit, delete.
  * Stored in `patterns.json` or XML.

* **Misc Tab**

  * Reserved for future features.

## Section C — Secondary Update: Catalog Tool

### C1. General

* Catalog is a separate **main tab**.
* Toolbar buttons toggle: \[Main] ⇄ \[Catalog].

### C2. Structure

* Catalog contains 4 tabs:

  * TV Series
  * Movies
  * Anime
  * Get (import list).

### C3. Functionality

* Import text file (line = entry).
* Compare with defined databases.
* If exists → move from Get to correct category + add to On-Database file.
* On first run → generate On-Database file.
* Export function for On-Database entries.

### C4. Future Expansion

* Category-specific tools.
* Missing episode/movie detection.
